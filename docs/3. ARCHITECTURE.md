# Architecture

Summary only. The source of truth is the linked doc; when they disagree, the code wins, then that doc, then this file.

Source: [02-technical.md](02-technical.md) and [03-app-flow.md](03-app-flow.md).

## Stack
Next.js 16 (App Router, server actions), React 19, TypeScript, Tailwind 4; Postgres (Neon London in production, PGlite in `./data` locally); Cloudflare R2 for files; Resend for email; Vercel (lhr1, Pro); Sentry; Capacitor 8 apps in `mobile/`; ClamAV scanner in `scanner/` (Cloudflare Containers).

## Hosts
`floortest.app` (product), `ops.floortest.app` (ops, own two-factor sign-in); split in `src/proxy.ts`.

## Data flow
Browser uploads go straight to R2 with signed URLs; the app stores metadata in Postgres; scheduled jobs run on Vercel Cron (`/api/cron/digest`, `/api/cron/purge`).

## Environments
`mobile-next` builds a Vercel preview (own database and bucket); `main` is production.
