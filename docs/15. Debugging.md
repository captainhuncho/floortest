# Debugging

Summary only. The source of truth is the linked doc; when they disagree, the code wins, then that doc, then this file.

Source: [operations.md](operations.md) (Monitoring; When something goes wrong).

## Where to look
Admin → Overview and Incidents; Vercel logs; Sentry; `/api/health`.

## Common problems
Site down: check Vercel and `/api/health`, promote the previous deployment. Nobody can sign up: check Turnstile, switch off Bot check. Emails missing: Admin → Emails sent and Resend. Backup missing: rerun `/api/cron/purge`. Full table in [operations.md](operations.md).

## Local
Stop the dev server before scripts that open `./data` (PGlite is single-process).
e2e tests failing with "frame was detached" or a form that never starts its bot check: a stale `.next/dev` folder (for example one left by another dev server or a branch switch) makes Turbopack's dev client reload the page on every connect. e2e now clears `.next/dev` before it starts (29 Oct); if it still happens, move `.next` aside and run `npm run e2e` again (28 Oct).
Typecheck failing with "Cannot find name 'RouteContext'" in a fresh checkout: Next.js generates the route types into
`.next/types`. `npm run typecheck` now runs `next typegen` first, so it works without a prior build (30 Oct). e2e clears
`.next/dev` before it starts, so the folder typegen leaves behind does not affect it.
