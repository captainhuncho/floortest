# Debugging

Summary only. The source of truth is the linked doc; when they disagree, the code wins, then that doc, then this file.

Source: [operations.md](operations.md) (Monitoring; When something goes wrong).

## Where to look
Admin → Overview and Incidents; Vercel logs; Sentry; `/api/health`.

## Common problems
Site down: check Vercel and `/api/health`, promote the previous deployment. Nobody can sign up: check Turnstile, switch off Bot check. Emails missing: Admin → Emails sent and Resend. Backup missing: rerun `/api/cron/purge`. Full table in [operations.md](operations.md).

## Local
Stop the dev server before scripts that open `./data` (PGlite is single-process).
e2e tests failing with "frame was detached" or a form that never starts its bot check: a stale `.next` folder (for example one left by `next typegen` or another dev server) makes Turbopack's dev client reload the page on every connect. Move `.next` aside and run `npm run e2e` again (28 Oct).
