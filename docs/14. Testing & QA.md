# Testing & QA

Summary only. The source of truth is the linked doc; when they disagree, the code wins, then that doc, then this file.

## Test types
- Unit tests: `tests/*.test.ts` (Node test runner via tsx), `npm test`.
- End-to-end: Playwright in `e2e/`, `npm run e2e` (port 3000 free).
- Permission checks: `npm run check:perms`.
- Smoke: `npm run smoke`.

## Release checks
Before every push: `typecheck`, `lint` (0 errors), `test`, `check:perms`; `e2e` when sending, review, downloads, receipts or auth change. Each production release has a report in [evidence/](evidence/).

## Manual QA
Browser and device checks run on this Mac; phone builds per [02-technical.md](02-technical.md).

## Five-person pre-beta gate (before 1 November 2026)
Five controlled testers complete the sender and receiver journeys on phone and desktop before access widens. Record the build, device/browser, tester role, result and evidence in one test report; group duplicate findings; fix and re-test blockers. Include interrupted and duplicate uploads, email verification and receipts, listen/decision/reply/download, session revocation, cross-account access checks, cron/job visibility, backup verification and one deletion/retry exercise. Use test audio and isolated test data for destructive or time-based scenarios.
