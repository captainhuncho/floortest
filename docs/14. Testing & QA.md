# Testing & QA

Summary only. The source of truth is the linked doc; when they disagree, the code wins, then that doc, then this file.

## Test types
- Unit tests: `tests/*.test.ts` (Node test runner via tsx), `npm test`.
- End-to-end: Playwright in `e2e/`, `npm run e2e` (port 3000 free).
- Permission checks: `npm run check:perms`.
- Smoke: `npm run smoke`.

## Release checks
Before every push: `typecheck`, `lint` (0 errors), `test`, `check:perms`; `e2e` when sending, review, downloads, receipts or auth change. Each production release has a report in [evidence/](evidence/).

## Manual QA
Browser and device checks run on this Mac; phone builds per [02-technical.md](02-technical.md).
