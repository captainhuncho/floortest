## Speed

The first requests from this Mac after the deploy took 16–20 s. Measured again by the Security session, these spikes
are this Mac's network, not the release: vercel.com itself took 75 s once in the same minute, and one floortest.app
request spent 11 s in TLS setup before the server saw it. Steady state from this Mac: about 0.5–0.9 s to first byte,
of which about 0.3–0.4 s is connect and TLS, so the server takes roughly 0.2–0.5 s. `/contact`, `/api/health` and static
paths hold at about 0.5 s. Not a regression; measured from this Mac's connection only.
