## What shipped
- `next` and `eslint-config-next` 16.3.8 → 16.4.1 (`c846b4f`), the first patched version for three critical advisories in every 16.0.0–16.4.0 release:
  - GHSA-2464-fhr4-w9xw: remote code execution in the image optimisation API with SVG files. FloorTest doesn't use `next/image`, so likely not reachable, but patched anyway.
  - GHSA-673q-mjm6-r5xr: remote code execution in `use cache` functions. FloorTest has no `use cache`.
  - GHSA-p3m5-59mp-jv5r: denial of service through Server Actions. **FloorTest is exposed** (24 files use them).
- Nothing else: the lockfile changes only the Next.js packages and their per-platform compiler binaries. 16.4.0's release notes list internal and experimental removals FloorTest doesn't use (no `experimental` settings, no PPR, no `use cache`).
