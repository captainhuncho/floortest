## What shipped
- **Passkeys** (#75): desk accounts can add a passkey in Settings → Security and sign in with it. Migration
  `0105_passkeys` adds the tables `passkeys` and `passkey_challenges`, both with row-level security; nothing existing
  changes. New packages `@simplewebauthn/server` 14.0.3 and `@simplewebauthn/browser` 14.0.0 (vetted by Safety).
  A passkey is tied to the address it was made on, so one made on a preview doesn't work on floortest.app.
- **No mobile-next into main** (#76): `.github/workflows/no-mobile-next-to-main.yml` closes any pull request from
  `mobile-next` into `main` (`pull_request_target`, never checks out the PR's code, `pull-requests: write` only).
  `docs/working.md` rule 2 notes it.
- **e2e clears the dev cache** (#76): `playwright.config.ts` removes `.next/dev` before the test server starts, after a
  stale one failed the sign-up tests twice today.
