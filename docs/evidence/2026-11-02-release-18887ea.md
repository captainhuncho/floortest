## What shipped
- #356: any ops action that answers with an undo token (through `OpsForm`, `ConfirmButton`, `OpsButton`, `ProofForm`
  or the Moderation queue) shows "Sending in 5 s · Undo" with ⌘Z / Ctrl+Z, then "Sent". Hovering or focusing pauses the
  count, but Undo always closes 1 s before the server's 8 s hold; after Undo the page refreshes so the row is back.
  `src/app/admin/kit/Toaster.tsx`, `heldLeft` in `kit/core.ts`. New `e2e/ops-held-sends.spec.ts`.
- #360: the proxy sends `X-Robots-Tag: noindex, nofollow, noarchive` on every path except the public pages listed in
  `src/lib/search-index.ts`, and the sitemap uses the same list. `robots.txt` now blocks only `/dashboard`, `/admin`,
  `/api/`, the sign-in forms, `/newsletter/` and `/sent/reopen/`, so crawlers can read the noindex on link pages instead
  of listing the bare link. Test `tests/search-index.test.ts`.
- #361: `tests/scan-budget.test.ts`'s scan deadline in the test raised from 400 ms to 10 s (it ran out under parallel
  load); `e2e/sharing.spec.ts` asks as its own seeded stranger per repeat (`scripts/seed.ts`, test seed only), so the
  two-a-day request limit no longer trips a rerun. Test code only.
