## What shipped
- Signed-out session checks under load: only real sessions are remembered, so made-up tokens can't fill the
  2,000-entry list or push real sessions out; at most 16 lookups reach the database at once (the rest count as
  signed out); after a failed lookup, new ones are refused for 1.5 s without a query.
- Turning a switch on or off: the write only happens when the value changes, so two flips at once make one lock
  generation; the admin log line is written in the same transaction, and a failed log line undoes the flip. The
  switch cache is cleared only after the change is saved.
