## What shipped
- Profile links are compared by the profile they point to, so `www.`, a trailing slash or `?igsh=` on a platform's
  main host no longer count as a new profile and no longer drop the Verified mark. Different usernames, short links,
  videos, query strings and sites on shared hosts still count as different.
- Links are tidied only when saved; Instagram usernames follow Instagram's rules and post or reel links are refused.
- A verified account is asked "Remove your Verified mark?" before saving a different name or different profiles.
