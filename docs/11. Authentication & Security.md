# Authentication & Security

Summary only. The source of truth is the linked doc; when they disagree, the code wins, then that doc, then this file.

Source: [SECURITY.md](../SECURITY.md), [API_GUIDE.md](API_GUIDE.md) and [02-technical.md](02-technical.md) (Auth row).

## Sign-in
Own sessions (hashed tokens, HttpOnly cookie); scrypt passwords; breached-password check (Have I Been Pwned, k-anonymity); TOTP two-factor; Google OAuth (state + PKCE). Ops has its own sign-in with two-factor every time.

## Roles
Desk roles: Owner, A&R / Admin, Member (`requireRole`); checked by `npm run check:perms`.

## Protections
Cloudflare Turnstile on public forms and after repeated failed sign-ins; Vercel Firewall rate limits; private links expire; antivirus scan on uploads when `SCAN_URL` is set.

## Secrets
Vercel environment variables only; rotation steps in [operations.md](operations.md).

## Risks and testing
Threat model and known limits in [SECURITY.md](../SECURITY.md); pentest brief in [pentest-brief.md](pentest-brief.md). GitHub scanning: CodeQL on pushes, pull requests and weekly, and dependency review on pull requests (fails on high); details in SECURITY.md, Change and verification requirements.
