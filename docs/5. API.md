## Conventions
Access classes (public, authenticated receiver, shared access, capability links, admin, service callbacks), validation, errors, audio responses: [API_GUIDE.md](API_GUIDE.md).

## App API
`/api/v1` for the mobile app: `auth/login`, `auth/refresh`, `auth/logout`, `me`, `queue`, `tracks/:id/decision`, `tracks/:id/audio`, `receivers/:handle`, `sends`, `sends/complete` (200 `{ token }`, or 202 `{ held: true, message }` while the virus scanner sleeps: the track arrives within about 15 minutes), `collections`, `prepare`.

## Webhooks
Resend delivery webhook `/api/webhooks/resend`.

## Rate limits
Vercel Firewall: 300 requests a minute per address on `/api/*`, 60 a minute on sign-in pages; per-action caps in code.
