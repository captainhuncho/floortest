## Branches and release
Work on `mobile-next`; `main` is production, only on the owner's "ship it". Message running sessions before shipping; ship from your own worktree.

## Docs rule
A change to a feature, route, screen rule, table/permission or the plan updates the matching doc in the same commit, including these 15 numbered files.

## Never
Secrets in the repo; editing legal pages; installing third-party hooks or plugins; deleting buckets, databases or accounts; changing production settings unasked.
