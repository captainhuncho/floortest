# Database

Summary only. The source of truth is the linked doc; when they disagree, the code wins, then that doc, then this file.

Source: [05-data.md](05-data.md) and [DATABASE.md](DATABASE.md).

## Engine
Postgres: Neon in production, a separate database for previews, PGlite locally. Raw SQL through `q` helpers in `src/lib/db`.

## Schema and access
Main tables by owner and who can see what: [05-data.md](05-data.md). Permission checks: `npm run check:perms` (admin perms, desk roles, RLS).

## Migrations
Append-only in `src/lib/db/migrations.ts`, run by `vercel-build`; a migration reaches production only when shipped.

## Backups and retention
Nightly backup and recovery copy (`src/lib/vault.ts`); retention rules in [05-data.md](05-data.md) and [operations.md](operations.md).
