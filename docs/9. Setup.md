Source: [README.md](../README.md) and [02-technical.md](02-technical.md).

## Prerequisites
Node 22.5+. No services needed locally: PGlite and a files folder under `./data`; emails are logged.

## Install and run
`npm install`, `npm run seed` (wipes `./data`), `npm run dev`. Stop the dev server before any script that opens `./data`; use a scratch `DATA_DIR` for experiments.

## Environment variables (names only)
`APP_URL`, `APP_SECRET`, `DATABASE_URL`, `DB_POOL_MAX`, `DB_AUTO_MIGRATE`, `DATA_DIR`, `STORAGE_DRIVER`, `S3_BUCKET`, `S3_REGION`, `S3_ENDPOINT`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY`, `S3_FORCE_PATH_STYLE`, `RESEND_API_KEY`, `MAIL_FROM`, `MAIL_REPLY_TO`, `BETA_INVITE_CODES`, `CRON_SECRET`, `SUPPORT_EMAIL`, `BACKUP_KEY`, `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY`, `PWNED_CHECK`, `ALERT_WEBHOOK_URL`, `NEXT_PUBLIC_SENTRY_DSN` and others in `.env.example`.
